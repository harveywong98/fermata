# 类型描述核验

这是名称语义核对，不是客户字段字典认证。原文件仅有类型名称，没有表结构、样例和枚举。未强行合并近义类型，也未给不明字段补造单位或算法。描述和问题由同一助手构造，存在措辞与任务设计偏差，成绩不能视作线上准确率。

## 公开依据

- [国家发改委输配电价解释](https://www.ndrc.gov.cn/xxgk/jd/jd/202305/t20230515_1355769_ext.html)：输配电价用途、电压等级、费用项目区别。
- [国家能源局直接交易合同](https://zjb.nea.gov.cn/u/cms/www/202103/30145839y73b.pdf)：电量使用兆瓦时等计量口径。
- [国家能源局许可申请表](https://gsb.nea.gov.cn/dtyw/tzgg/202504/P020250403623625780210.pdf)：电力业务许可类别与许可证编号。

这些来源仅支撑通用概念，不能证明具体客户字段的单位、关联和枚举。

## 测试标注边界

- 更新时间与更新日期：输入未提供精度时，命中任一作为可接受结果；不能人为断言一定分别是秒级和天级。
- 合同卖方与主体名-卖方：未提供表上下文时，任一命中接受。
- 疑义字段仍在100项候选中参与竞争，但不构造确定的单标签正例。
- 多目标集合基于本次100项目录人工枚举，统计全部相关项覆盖；不承诺覆盖目录外的业务。
- 短查询为缺上下文对照组，不能将其低命中归因于模型错误。
